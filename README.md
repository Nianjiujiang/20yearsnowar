# 二十年停战

二战题材多人策略战棋 · 单文件网页游戏

---

## ✨ 特色

- **零依赖单文件**：纯 HTML/CSS/JS，无外部库、无联网，双击即玩
- **二战欧洲战场**：数百个陆地与海洋地块，支持 2D / 3D 双渲染
- **8 国混战**：真人 + AI 任意组合
- **海陆空三军**：潜艇 / 轻舰 / 重舰 / 航母 + 步兵 / 机步 / 火炮 / 坦克 + 机场空袭
- **各国独有兵种**：每个国家都有特色单位
- **国家机制**：大国背负历史包袱，达成条件觉醒；小国另有自己的优势
- **外交系统**：隐藏数值，战争与援助都会影响各国关系
- **史官系统**：全程战报自动记载，可导出、可回放整局
- **海峡封锁**：控制关键海峡两侧即可封锁航道

详细规则见 [`docs/规则书.md`](docs/规则书.md)。

---

## 🚀 快速开始

用浏览器直接打开 `二十年停战.html` 即可运行，无需安装、无需联网、无需服务器。

1. 打开页面，在设置中选择国家、玩家/AI 席位与胜利条件
2. 开始对局！

---

## 🎮 玩法概要

- **回合制**：各国轮流，每回合分**建造阶段**（基建 / 工厂 / 机场 / 港口 / 造船 / 招募 / 空袭）与**行动阶段**（调动 / 战斗）
- **双资源**：产能（基建与建造）与军火（募兵造船），由民用/军用工厂产出
- **胜利条件**：多种模式可选（如占领所有地块、占领所有工厂、占领所有首都）

---

## 🕹️ 操作指南

- **调动/攻击**：按住己方单位拖拽到目标地块——可调动亮绿边，可攻击亮红边
- **数字键**：`1` 基建　`2` 民用工厂　`3` 军用工厂　`4` 机场·空袭　`5` 港口·造船　`6-9` 募兵·舰种　`0` 特殊兵种·联合行动
- **空格**：下一回合
- **📜 史官**：左下角查看战报；「读史」导入战报文件回放整局
- **无海战模式**：设置页可关闭海战
